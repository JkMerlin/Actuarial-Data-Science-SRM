# Society of Actuaries (SOA) Exam SRM Preparation Portfolio
**Statistics for Risk Modeling**

## 📌 Project Overview

This repository is a technical portfolio and structured learning environment
for my preparation for the **Society of Actuaries (SOA) Exam SRM
(Statistics for Risk Modeling)**.

The primary goal is to develop and maintain practical, transferable skills in
statistical modeling, data analysis, programming, and quantitative
communication while preparing for the examination.

Rather than treating the required readings and examples solely as examination
material, I use them as opportunities to:

- Apply statistical learning concepts through practical examples
- Implement analytical methods in **R**
- Incorporate **SQL** whenever relational data manipulation or querying is
  appropriate
- Compare analytical approaches across tools
- Practice reproducible data-analysis workflows
- Develop clear visualizations and communicate analytical findings
- Track learning progress programmatically
- Strengthen the ability to translate quantitative results into an
  understandable narrative

The repository therefore combines **actuarial preparation, statistical
learning, data analysis, SQL, programming, and data storytelling** into one
reproducible portfolio project.
---

## 🛠️ Core Competencies & Skills Demonstrated
Through the syllabus material archived here, I actively apply and demonstrate proficiency in:
* **Supervised Learning (Regression & GLMs):** Simple/Multiple Linear Regression, Generalized Linear Models.
* **Supervised Learning (Classifiers & Trees):** Decision Trees, Pruning algorithms, Bagging, Random Forests.
* **Time Series Modeling:** Stationarity testing, Autoregressive (AR), Moving Average (MA), and ARIMA forecasting.
* **Unsupervised Learning:** Dimensionality reduction via Principal Component Analysis (PCA) and cluster identification.
* **Model Validation:** Evaluating bias-variance tradeoffs, Cross-Validation (K-fold, LOOCV), and validation metrics.

## 🧠 Learning Approach

The repository follows a practice-oriented approach to professional
examination preparation.

The SOA encourages candidates to work exercises associated with the required
readings as part of the learning experience. I extend this approach by using
selected textbook and study examples as opportunities for additional
implementation and analysis.

For appropriate problems, I may solve the same analytical question using
different tools or representations, including:

| Approach | Purpose |
|---|---|
| **Mathematical solution** | Develop conceptual and quantitative understanding |
| **R implementation** | Practice statistical computing and reproducible analysis |
| **SQL implementation** | Maintain practical relational-data querying skills |
| **Visualization** | Explore patterns and communicate results |
| **Written interpretation** | Translate quantitative results into a clear analytical story |

Not every problem requires every tool. SQL is incorporated when the structure
of the problem naturally lends itself to data extraction, filtering,
aggregation, joining, or other relational operations.

## 📖 Data Storytelling

In addition to technical preparation for SRM, I am developing stronger
data-communication skills through the study of **_Storytelling with Data_ by
Cole Nussbaumer Knaflic**.

The goal is to move beyond producing technically correct analyses toward
communicating quantitative results clearly and effectively.

When appropriate, analyses in this repository will emphasize:

- Identifying the primary analytical message
- Choosing visualizations based on the question being asked
- Reducing unnecessary visual complexity
- Directing attention toward important findings
- Using appropriate comparisons
- Providing sufficient context for interpretation
- Combining quantitative evidence with a clear narrative

This perspective will be incorporated into future R and SQL projects,
particularly when presenting statistical-learning results.
