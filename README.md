# Society of Actuaries (SOA) Exam SRM Preparation Portfolio
**Statistics for Risk Modeling**

## 📌 Project Overview
This repository serves as a centralized technical archive and project tracking system for my preparation for the **Society of Actuaries (SOA) Exam SRM (Statistics for Risk Modeling)**. 

Beyond passing the formal professional examination, the core objective of this repository is to demonstrate an advanced, practical understanding of predictive modeling, statistical learning theories, and data science methodologies as they apply to actuarial risk analysis.

---

## 🛠️ Core Competencies & Skills Demonstrated
Through the syllabus material archived here, I actively apply and demonstrate proficiency in:
* **Supervised Learning (Regression & GLMs):** Simple/Multiple Linear Regression, Generalized Linear Models.
* **Supervised Learning (Classifiers & Trees):** Decision Trees, Pruning algorithms, Bagging, Random Forests.
* **Time Series Modeling:** Stationarity testing, Autoregressive (AR), Moving Average (MA), and ARIMA forecasting.
* **Unsupervised Learning:** Dimensionality reduction via Principal Component Analysis (PCA) and cluster identification.
* **Model Validation:** Evaluating bias-variance tradeoffs, Cross-Validation (K-fold, LOOCV), and validation metrics.

---

## 📂 Repository Architecture
The workspace is structured into the following operational directories:
* `summaries/` — Granular technical notes detailing statistical assumptions and conceptual definitions.
* `code-implementations/` — Programmatic applications (R / Python) of textbook methodologies.
* `cheatsheets/` — Consolidated, high-density reference guides outlining core formulas.
* `soa-samples/` — Comprehensive solutions to official SOA sample examination problems.
